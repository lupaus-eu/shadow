## DEV ympäristön setup
- Luo omalla koneella (VS Codella) hakemisto, mihin projektin kehitys tulee.
- Aja ko. hakemistossa: `git init`
- Aseta origin pointtaamaan github repoon: `git@github.com:reflector-oy/schatten.git`. Huom! On syytä asettaa ssh avaimet etukäteen kuntoon.
- Hae main haara githubista: `git pull origin main`. Nyt pitäisi olla valmista kehitystä varten. Ks. ohjeet.
