# Separate External Signals from Events

Platform-provided External Signals remain sourced, read-only records distinct
from customer-created Events. Organization Admins select and assign signals to
Yearclocks, while Yearclock Editors may create linked response Events. This
preserves provenance and keeps observed external conditions separate from
organizational intent for future analysis and simulation.

External Signals are outside V1 (ADR-0027). ADR-0006 supersedes the Area-based assignment described here.
