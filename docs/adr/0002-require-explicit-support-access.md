# Require explicit Support Access

Platform Operator staff have no standing access to an Organization's Event
content. A Support Agent may access that content only through an explicit,
Organization-specific, time-limited, and audited Support Access grant;
Platform Admin authority alone does not grant customer-content access. This
preserves the confidentiality boundary needed for sensitive HR, board, and
management planning while still permitting accountable support.

Refined by ADR-0020, which adds customer approval and the no-bypass rule.
