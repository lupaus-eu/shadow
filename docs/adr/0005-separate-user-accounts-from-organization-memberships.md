# Separate User Accounts from Organization memberships

User Accounts may belong to multiple Organizations through independent memberships. Each Organization has one or more Owners and may never have zero; new ownership requires recipient acceptance. Owners may manage memberships, billing, and Organization deletion, but removing a membership never deletes the underlying User Account or affects its access to other Organizations. This supports consultant-led setup and later customer control without transferring identities.
