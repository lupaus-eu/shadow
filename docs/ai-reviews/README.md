# AI Review Archive

Tämä hakemisto sisältää Step 13:n versionhallittavat AI-review-recordit.

Lue ennen uuden recordin luontia:

```text
docs/AI-REVIEW-RECORDS.md
```

Käytä taskikohtaista hakemistoa ja jatkuvaa numeroa:

```text
TASK-051/review-001.json
TASK-051/review-002.json
```

Älä tallenna tähän promptia, raakaa mallivastausta, patchia, salaisuutta,
tokenia, henkilötietoa tai query-parametreja sisältävää URL:ia.
