## NIS2 (Finnish Cybersecurity Act 124/2025)

**verify** with counsel. A cloud computing provider is in scope only above the size threshold (medium-sized or
larger); a small provider is probably outside it. Yearclock is a small operator at present, so no registration or
reporting duty is assumed. Revisit when headcount or turnover grows, or if a customer's contract demands NIS2-level
measures. Meanwhile the measures on the security page apply.

## EU AI Act

**verify** with counsel. Yearclock does not provide or deploy an AI system of its own. An agent that a person connects
through the MCP interface is that person's choice, runs on the provider the person selects, and acts with the person's
own permissions; Yearclock stores no agent conversations (see [README.md](README.md)). No duty is assumed to arise.
Revisit if Yearclock adds its own AI features.
