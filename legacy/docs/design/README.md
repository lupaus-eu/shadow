# Design documentation

Keep durable Shadow UI and UX principles, interaction patterns, accessibility
decisions, and visual-system guidance here. Feature-specific UI exploration
belongs in its `.scratch/<feature>/technical-design.md` until the decision is
stable enough to guide future work. Technical boundaries of the frontend are
in [`docs/architecture/overview.md`](../architecture/overview.md).

The current visual system is implemented in `frontend/src/styles/`
(`tokens.css`, `reset.css`, `components.css`, `app.css`) and the shared
components in `frontend/src/components/`. No durable design guidance has been
written yet; add it here when a feature settles a pattern.
